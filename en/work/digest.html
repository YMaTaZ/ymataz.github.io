01The chain

Four segments, each with one place it can fail

I will start with an admission: the only user of this product is me. So its value is not that other people can use it, it is that I want to open it every day — and that set the trade-off in every segment.

02Decision 1 / 2

Ranking cannot be handed to the model

The most obvious approach is: throw all of today's news at the model and have it output "the three most important items today". I built that version, then dropped it.

The situation
The model can output "the three most important items today" directly
What I assumed
Letting it judge is less work and smarter
What was actually true
Hand the criteria to the model and the output drifts, and cannot be explained
So I changed
I hard-coded the ranking rules; the model only summarises and scores
What it cost
The rules need manual upkeep; new kinds of news get missed

If the same batch of news gives me these three items today and a different three tomorrow, the tool has no credibility. Ranking has to be recomputable.

03Decision 2 / 2

Failure has to be visible

The situation
When the scheduled job failed, there was no daily digest that day
What I assumed
A few retries would be enough
What was actually true
Silent failure is the worst case: people assume there was no news today
So I changed
On failure it sends one notification: "I broke today"
What it cost
One extra interruption, in exchange for trust

This is the same decision as "failure must be visible" in EODD, and the two confirm each other: when a system says nothing, people cannot tell "all fine" from "broken".

What one person using it for thirty days learned

One person using it for thirty days will find more problems than five people reviewing it for three — because it is really being used every day. This is the only methodology point I want to make from this project: a rough version that gets used daily beats a perfect version that gets praised in review.

It serves me and no one else. I did no multi-user design for "other people might want this" — that is a different job, I did not do it, and I do not write it up as done.
